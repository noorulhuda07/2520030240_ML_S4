## 🎯 Course Outcomes

The course work focuses on the following major outcomes:

* **CO1:** Analyze the end-to-end Machine Learning system lifecycle from data collection and feature engineering to training, evaluation, deployment, and monitoring.

* **CO2:** Apply linear supervised-learning models including Linear Regression, Ridge, Lasso, Elastic Net, Logistic Regression, and Multinomial Logistic Regression.

* **CO3:** Apply tree-based supervised-learning models including Decision Trees, Random Forests, and Gradient-Boosted Trees such as XGBoost and LightGBM.

* **CO4:** Apply unsupervised-learning techniques including K-Means, Hierarchical Clustering, DBSCAN, PCA, t-SNE, UMAP, and anomaly detection.

* **CO5:** Analyze Machine Learning model performance using train/validation/test splits, cross-validation, classification and regression metrics, calibration, and hyperparameter search.

* **CO6:** Apply Machine Learning engineering practices including feature stores, training-serving skew avoidance, model packaging, REST-based serving, monitoring, and model retraining.

## 🚀 Featured Project — PhishGuard AI

**PhishGuard AI** is a Machine Learning web application that analyzes URLs and estimates whether a link exhibits characteristics associated with phishing.

The application uses:

* Character-level TF-IDF
* Numeric URL features
* TLD encoding
* Logistic Regression
* Random Forest
* Gradio

The application provides URL analysis, risk estimation, explanations for detected URL characteristics, brand impersonation checks, and typosquat analysis.
